# 대표 프로젝트 홈과 이력 분리

작성일: 2026-10-11 (Asia/Seoul)
상태: 코드·문서 작성 완료 / 사용자 확인 대기

## 요청과 반영

사용자가 홈에서 대표 프로젝트와 가장 보여주고 싶은 경험에 집중하고, 기존 프로필/이력은 새 네비게이션 메뉴로 옮기도록 요청했다. 목록용 소개를 확대하는 대신 홈 전용 구성을 작성했다.

- 홈: TruckWorks 전용 대형 타이틀과 공장 이미지, 핵심 문장, 전용 3관점 선택(공간/AI 근거/직접 제작), 상세 사례 진입, 다른 프로젝트/이력 연결.
- 프로젝트: 기존 목록과 상세 경로 유지. 홈은 목록용 TruckWorksFeature를 사용하지 않는다.
- 이력: 새 #resume 경로로 기존 사진·개인 정보·학력·경력·교육·기술·자격·프로젝트 경험·PDF 다운로드 이동.
- 소개: 기존 경험 지도/선택형 소개 유지.
- 600px 이하에서는 메뉴를 별도 행에 배치해 네 메뉴가 함께 보이도록 작성.

## 코드 연결

navigation.js에 resume 항목을 추가하면 useHashPage의 기존 navigationItems 조회가 경로를 인식한다. App.jsx에서 ResumePage를 연결한다. 기존 상세 경로 처리와 목록 스크롤 보존은 변경하지 않았다.

HomePage.jsx/css는 전용 첫 화면과 소개/연결 영역을 담당한다. HomeProjectFocus.jsx/css는 세 관점의 선택 상태를 관리하고 data/homePerspectives.js가 이미지·문장·설계 흐름을 제공한다. ResumePage.jsx/css는 이전 홈 이력 부분을 옮겨 담는다.

사진은 기존 자체 Blender 렌더를 재사용하며 실제 실행/AI 응답으로 표시하지 않는다. 관점 선택은 설명을 바꾸는 인터랙션이고 생산이나 모델 호출이 아니다. 실제 데모 URL·영상·성과 수치를 새로 만들어 넣지 않았다.

## 사용자 직접 확인

C:\Users\sp287\WebstormProjects\portfolio에서 필요 시 npm run dev로 실행한다.

1. 홈에서 이력 나열 없이 대표 프로젝트 화면이 먼저 보이는지 확인한다.
2. 메뉴의 이력 클릭과 직접 #resume 진입, 새로고침·뒤로가기를 확인한다. 사진/학력/경력/교육/기술/자격/프로젝트 경험과 PDF 다운로드가 유지되어야 한다.
3. 홈 세 관점 버튼을 마우스/Tab/Enter/Space로 선택한다. 선택 표시와 제목·이미지·설명이 함께 바뀌어야 한다.
4. 홈의 두 상세 링크, 프로젝트 전체, 이력 링크 및 기존 소개/프로젝트 상세 이동을 확인한다.
5. 데스크톱과 320px/390px 폭에서 제목/메뉴/이미지/하단 문장이 잘리지 않는지 확인한다. 모바일은 이미지와 문장을 순서대로 읽도록 배치했다.
6. 필요 시 npm run build와 npm run lint를 직접 실행하고 결과를 전달한다.
